# 公开复盘摘要模板

文件位置：`content/reviews/<match_id>.md`

```markdown
---
match_id: <match_id>
title: <简短标题>
hero: <英雄>
result: <胜/负>
played_at: <比赛时间>
duration: <比赛时长>
patch: <版本>
visibility: public
tags: [<标签1>, <标签2>]
evidence_level: <数据等级>
assessment: <good/mixed/poor>
---

# 一句话结论

用一句话说清这局最值得记住的结果和方向。

# 表现评价

做得好的：<可复用优点>。

需要改进的：<最明确的问题、严重程度和后果>。

# 对线建议

先说明当前数据能否支持对线结论，再给一个下一局能执行的动作。

# 团战建议

围绕进场顺序、目标选择、技能/保命资源和团后地图转化给建议。

# 决策失误

只列最确定、影响最大的错误。无法确认的地方标为“未知”，不要把推测写成事实。

# 下一局行动

1. <动作一>
2. <动作二>

# 数据说明

说明公开摘要使用的数据范围，以及哪些细节需要录像确认。
```
